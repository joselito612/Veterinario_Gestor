# Constitución

1. Stack mínimo: TypeScript, React, Node.js y PostgreSQL; toda dependencia requiere justificación.
2. Ningún cambio de código se implementa sin una spec aprobada y trazable.
3. La lógica de negocio no depende de React, rutas HTTP ni componentes de interfaz.
4. Cada regla de negocio y corrección de error incluye tests automatizados.
5. Los datos clínicos, inventario y auditoría se persisten en PostgreSQL; nunca solo en memoria.
6. Código, nombres técnicos y commits en inglés; interfaz, validaciones y mensajes al usuario en español.
